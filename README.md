# teaching-archive

An archive of course websites I built while teaching at the Australian National
University. These are frozen snapshots---the courses themselves have moved on,
but the materials are still here for anyone who finds them useful.

Each site is built with [Astro](https://astro.build) and
[astro-theme-anu](https://gitlab.anu.edu.au/u2548636/astro-theme-anu), deployed
to [teaching.benswift.me](https://teaching.benswift.me) via GitHub Pages.

## Sites

- [COMP1720](https://teaching.benswift.me/comp1720/) --- Art & Interaction
  Computing
- [COMP2300](https://teaching.benswift.me/comp2300/) --- Computer Organisation
  & Program Execution
- [COMP2710 LENS](https://teaching.benswift.me/comp2710-lens/) --- Laptop
  Ensemble
- [Computing IoT BIT](https://teaching.benswift.me/compiot-bit/) --- China Study
  Tour
- [EXTN1019](https://teaching.benswift.me/extn1019/) --- Creative Computing
