## [p5js.org](https://p5js.org/)

This is the [main p5js website](https://p5js.org/), and there's lots of good info there:

- the [p5js reference](https://p5js.org/reference/) has all the details on
  *every* function and variable you'll need to care about in the p5 library
- the [p5js examples page](https://p5js.org/examples/) is a good place to see
  how different things can be done using p5
- the [p5js learn page](https://p5js.org/learn/) has some useful tutorials and
  guides

## [tonejs](https://tonejs.github.io/)
This is the [main tonejs website](https://tonejs.github.io/), and there's some good info there:

- the [tonejs docs](https://tonejs.github.io/docs/14.7.77/index.html) has all the details on
  *every* class and function you'll need to care about in the tonejs library
- [examples](https://tonejs.github.io/examples/) include basics, instruments, effects, timing and visualisation (e.g. [synching audio and animation](https://tonejs.github.io/examples/funkyShape)) 
- [this site](https://pdm.lsupathways.org/3_audio/) includes tutorials, exercises and examples [LSU Pathways Tone.js page](https://pdm.lsupathways.org/3_audio/)

## [ml5js.org](https://ml5js.org/)
This is the [main ml5js website](https://ml5js.org/), and there's some good info there:

- [Getting Started](https://learn.ml5js.org/#/) - the quick start guide
- [The Reference](https://learn.ml5js.org/#/reference/index) - details about all the classes for ml5.js
- [The Community](https://ml5js.org/community) - what people are doing with ml5.js

## [MDN JavaScript reference](https://developer.mozilla.org/en-US/docs/Web/JavaScript)

The [Mozilla Developer
Network](https://developer.mozilla.org/en-US/docs/MDN/About) is *the best* place
to get free online documentation, tutorials and guides on all things web
development.

Since this course is all in JavaScript then the [JavaScript reference
homepage](https://developer.mozilla.org/en-US/docs/Web/JavaScript) is probably
the best place to start, but you can't go wrong exploring other parts of the MDN
(e.g. their [references & guides section](https://developer.mozilla.org/en-US/docs/Learn))

Don't be tempted to go to [w3schools](https://www.w3schools.com/default.asp),
really not that useful (correct and up-to-date)[^w3schools] compared to the MDN.

[w3schools]:
    Look, w3schools is fine---there's even some good stuff on there in places, but overall the MDN is much higher quality and more up-to-date. After all, [Mozilla actually make a web browser](https://www.mozilla.org/en-US/firefox/new/), so they know what they're talking about with this stuff.

## Alternative p5js Tutorials
* [Coding Train p5.js](https://thecodingtrain.com/tracks/code-programming-with-p5-js)
   While this site looks like it is aimed at a lower age group - it has been created by the wonderful [Daniel Schiffman](https://tisch.nyu.edu/about/directory/itp/1984778605), who is also on the board of the Processing Foundation and involved with the ml5.js community.
* [Happy Coding: p5.js](https://happycoding.io/tutorials/p5js/)
  This site is open and free. Information is static, but has a different set of exercises and explanations.
* [Code Academy: p5.js](https://www.codecademy.com/courses/learn-p5js/articles/welcome-to-learn-p5-js)
  This site tries to get you to sign up. The interactive coding exercises require specific answers (your correct solution might not be the same as theirs and so you cannot move to the next exercise until you do it their way - which I always find frustrating). Not recommended.
