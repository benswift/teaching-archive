## Textbooks (Available online through ANU Library)

This course refers to three core books that cover p5.js, topics in interaction design, and interactive art and three extra books that have more detail on particular aspects of interactive art. The first book covers the technical content for the course, but the others will help you understand how to make interactive artworks that are _good_, and not just _functional_.

Core books:

- [**Make: Getting Started with p5.js**](https://anu.primo.exlibrisgroup.com/permalink/61ANU_INST/1alil8h/alma991026796370507631). Lauren McCarthy, Casey Reas, and Ben Fry. 2015. ([ANU link](https://anu.primo.exlibrisgroup.com/permalink/61ANU_INST/1alil8h/alma991026796370507631))

- [**The Design of Everyday Things: Revised and Expanded Edition**](https://anu.primo.exlibrisgroup.com/permalink/61ANU_INST/1csbe8o/cdi_globaltitleindex_catalog_348534610). Don Norman. 2013. ([ANU link](https://anu.primo.exlibrisgroup.com/permalink/61ANU_INST/1csbe8o/cdi_globaltitleindex_catalog_348534610))

- [**The art of interaction: what HCI can learn from interactive art**](https://anu.primo.exlibrisgroup.com/permalink/61ANU_INST/1csbe8o/cdi_igpublishing_primary_MCPB0006384). Ernest Edmonds and John M Carroll. 2018. ([ANU link](https://anu.primo.exlibrisgroup.com/permalink/61ANU_INST/1csbe8o/cdi_igpublishing_primary_MCPB0006384))

Extra books:

- [**The Nature of Code**](https://natureofcode.com). Daniel Shiffman. 2024. ([free online link](https://natureofcode.com))

- [**Electronic and Computer Music**](https://anu.primo.exlibrisgroup.com/permalink/61ANU_INST/1alil8h/alma991026906340307631). Peter Manning. 2013 ([ANU link](https://anu.primo.exlibrisgroup.com/permalink/61ANU_INST/1alil8h/alma991026906340307631))

- [**Coding Art: The Four Steps to Creative Programming with the Processing Language**](https://tinyurl.com/yyruvhe4). Mathias Funk and Yu Zhang. 2021. ([ANU link](https://tinyurl.com/yyruvhe4))

## Art and Interaction Bibliography

Charles Martin maintains a bibliography of useful resources about interactive computer art and music: 

- <https://cpmpercussion.github.io/art-and-interaction-bibliography/>

This list is especially useful for figuring out "recent developments" in art and interaction computing.

The repo is [here](https://github.com/cpmpercussion/art-and-interaction-bibliography) so if you want to add something, make a pull request!

## Other Resources:

Here's some extra references that you might find useful:

- the [p5js reference](https://p5js.org/reference/) has all the details on
  *every* function and variable you'll need to care about in the p5 library
- the [p5js examples page](https://p5js.org/examples/) is a good place to see
  how different things can be done using p5
- the [p5js learn page](https://p5js.org/learn/) has some useful tutorials and
  guides
- Learn JavaScript with p5.js: Coding for Visual Learners. Engin Arslan. 2018. ([link](https://tinyurl.com/y5nzzf67))
- [Mozilla Developer Network JavaScript reference](https://developer.mozilla.org/en-US/docs/Web/JavaScript)
