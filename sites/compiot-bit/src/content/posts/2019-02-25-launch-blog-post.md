## Launch Post

Sigh. It's been a long journey - 3 months to be exact. We (Aditya Chilukuri and I) had our ups and downs throughout the project but it was all worth it in the end. We had our final exhibition last Friday (22nd February, 2018) and honestly, it went better than expected.

So we spent our entire time trying to set up a server and get it to send/receive to and from the PS Band app that we made. We got a python server to receive and send data between different laptops, but were unable to use the server along with the app. Unfortunately, we realised that the server we won't be able to get it working on Thursday.

Going into panic mode and realising the the exhibition was literally in less than 24 hours, we decided to get rid of the server completely and focus on the UI instead so we had something to show at the demo. However, this proved to be less trivial than expected and took us quite a while - infact, we barely finished in time for the actual exhibition.

Buuuut, it's finally done. We, more or less, implemented the idea I had envisioned a few weeks ago after coming back from Beijing, and while it may not be perfect, it's still a prototype :)
