# What's in the Works
## Scratch the PIR Motion Sensor, Ultrasonic is where its at
So if you remember from last week, I tried using a PIR motion sensor working. Spoiler alert; it's still not working. I tried altering the sensitvity, I tried tweaking the code - nothing. So as a testament to my impatience in dealing with faulty hardware, I decided to move on.

Since I was to use the PIR motion sensor to detect motion, that is if a human walks by, I had to think of alternative sensors that could work. One of these sensors that work similar to PIR (and which I had readily available on me coincidentally) was the Ultrasonic sensor.

![ultrasonic](/images/posts/razi/ultrasonic.jpg)
<sup>Picture of ultrasonic sensor</sup>

How this thing works is using like a bat. It sends out a perpetual sound through its two big speakers (which we can't hear by the way) and detects how long it takes for the sound to deflect of a surface and get picked up by the sensor. The sensor can then determine the distance of an object in front of it using the duration of the sound deflection.

For it to program like a motion sensor, I had it so it would detect drastic changes in the distance of an object in front of it. If the sensor was initially facing a wall and something walks in between it, the sensor will have a drastic change in the distance reading which we can interpret as motion.
## Touch Screen and Basic Eyes
As I mentioned last week, this week I started to work on the output aspect of my program - namely the touchscreen.

To program the touchscreen, I needed to familiarise myself with a few libraries, namely the touchScreen, Adafruit_TFTLCD library and Adafruit_GFX. These libraries were responsible for allowing me to draw the graphics on the touchscreen and interact with it.

Because my device is a pet, I have started with the aim of drawing eyes that can interact on this touchscreen. I programmed simple wide rectangles as the eyes that move slightly around to give it some animation and liveliness. I have also made it so if you touch the eyes, the eyes will shut close (as if you touched an actually eye of an animal). The plan is to synchronise this eye to the inputs received from the sensors in this device.

![touchscreen eyes](/images/posts/razi/touchscreen.jpg)
<sup>Picture of Touch Screen with (Terribly Drawn) Eyes</sup>

One problem I encountered was the fact that the touch screen was a shield, and as a result used almost all the pins on the arduino. Since the pins are occupied, this leaves little room for other sensors I had planned for and others. One solution is to simply buy another bigger arduino board called the mega which has more pins. I'll refrain from buying more stuff in the meantime and do some more research in the following week.
