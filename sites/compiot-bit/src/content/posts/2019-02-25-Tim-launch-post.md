## Meshlight Launch

At long last the [github repo](https://github.com/tztimlee/Meshlight) for the artifact that Harry and I have been working on has been launched. Meshlight was designed as an interactive art piece designed to show the distance vector routing algorithm at work. The idea was that you would be able to see messages being passed between nodes on a network and then be able to turn off individual nodes and see them react in real time. Unfortunately we weren't able to get it working by the exhibition, but we were able to build the physical parts of the project to show, and pictures can be found on the github's readme page.

For more information about what we did and the components involved, check out the links below:
