### ESP IoT Development Framework

I downloaded the [Espressif IoT Development Framework](https://github.com/espressif/esp-idf?utm_source=platformio&utm_medium=docs), which is the offical development framework for ESP32.

I tried to write a small program which made use of some included libraries and printed out basic information about the chip such as its number of cores and features. However, I kept running into multiple problems, most of them related to not being able to open the .h files required by the program. I tried moving the files in various folders and changing the file paths but the issue is persisting.

![Error Message](/images/posts/chinmay/Week7Error.png)

I hope to fix this issue by tomorrow so I can move onto fixing other bugs which will almost definitely arise after I fix these ones.
